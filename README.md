# 🧩 Pokémon Search App (Frontend + Backend)

A simple full-stack Pokémon search app built using **HTML, CSS, JavaScript (Frontend)** and **Node.js + Express (Backend)**.  
You can search any Pokémon by name or get a random Pokémon — data is fetched from the [PokéAPI](https://pokeapi.co/).

---

## 🚀 Features

- 🔍 Search Pokémon by name  
- 🎲 Get a random Pokémon  
- ⚙️ Backend handles all API requests to PokéAPI  
- 🧠 Error handling for invalid Pokémon names  
- 💾 (Optional) API caching to reduce repeated external requests  
- 🔐 Uses `.env` for environment variables  
- 🌐 CORS configured for secure frontend-backend communication
